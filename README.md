# My Portfolio Website

## About the Project

This is my personal portfolio website, created to showcase my skills, projects, and a little bit about myself. I built it using HTML and CSS, keeping the design simple, clean, and easy to navigate.

The website is also responsive, so it can be viewed on different screen sizes, including mobile phones, tablets, and desktops.

## Features

- Personal introduction section
- About Me section
- Skills section
- Projects section with project cards
- Contact section
- Responsive layout for different devices
- Simple and clean design

## Technologies Used

- HTML5
- CSS3
